meml

🧠 explainable agent memory · written in Zig
Install Quick start Integrations Ops

A local, explainable long-term memory runtime for agents. MEML stores observations as subject–predicate–object triples, retrieves them with explainable activation, and consolidates verified feedback into durable memory — all in one zero-dependency binary, plus drop-in MCP servers, Skills and plugins for Claude Code, Codex, Pi, DeepSeek Harness, WorkBuddy and CodeBuddy.

Install the CLI

$ curl -fsSL https://mindon.dev/meml/install | bash
Installs meml to ~/.meml/bin and adds it to your PATH. Pin a version with curl -fsSL https://mindon.dev/meml/install | bash -s -- v0.1.0.

Quick Start

The CLI speaks a JSON-lines protocol: each request is a JSON object with an op field, each response is one JSON line. 

# Record an observation (subject–predicate–object triple)
meml '{"op":"observe","subject":"alice","predicate":"likes","object":"coffee"}'

# Retrieve related memory with explainable activation
meml '{"op":"activate","query":"coffee","details":true}'

# Persist memory to a local state file
meml '{"op":"persist","path":".meml/state.json"}'

# Batch mode: read requests from a file, or pipe them in
meml --file requests.jsonl
echo '{"op":"ping"}' | meml

Also available as an embeddable library: run zig fetch --save git+https://github.com/mindon/meml to add it to a Zig project.

Agent Integrations

Give any non-Zig agent a local long-term memory. The Skill teaches the agent how to use MEML; the plugin wires up a read-only meml_recall tool. Install both in one step each.

Install the Skill

$ curl -fsSL https://mindon.dev/meml/install-skill | bash
Downloads the meml-agent-memory Skill and copies it into detected hosts. For CodeBuddy and WorkBuddy it prepares the standard skills/<name>/SKILL.md plugin layout under ~/.meml/integrations.

Install the Plugin

$ curl -fsSL https://mindon.dev/meml/install-plugin | bash
Downloads integrations/ to ~/.meml/integrations, registers the meml MCP server for CodeBuddy, Claude Code and Codex when their CLIs are available, and prepares a compatible local plugin for WorkBuddy. Requires Node.js.

CodeBuddy & WorkBuddy

The plugin installer creates a compatible local plugin at ~/.meml/integrations/codebuddy/meml-plugin. CodeBuddy is registered automatically when its CLI is available; otherwise launch the plugin explicitly: 

# CodeBuddy
codebuddy --plugin-dir ~/.meml/integrations/codebuddy/meml-plugin

# WorkBuddy (the same plugin layout)
workbuddy --plugin-dir ~/.meml/integrations/codebuddy/meml-plugin

In CodeBuddy, the Skill is called from the plugin namespace as /meml-memory:meml-agent-memory. In WorkBuddy, enable the local plugin directory through its plugin manager. Restart or reload plugins after installation.
